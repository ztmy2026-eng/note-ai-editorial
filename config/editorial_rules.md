# 編集部の共通ルール(全Agentが必ず守る)

1. **事実・推測・意見・体験を区別する。**
   - 事実=出典(URLと日付)がある情報。出典のない断定は事実と書かない。
   - 推測=AIの推論。必ず「推測」と明記する。
   - 体験=筆者(ユーザー)が実際に経験したこと。
2. **体験を創作しない。** 筆者の体験・実践結果・数字が必要な箇所は、作り話にせず
   `【要入力:何を書いてほしいか】` という空欄にする。
3. **情報源を記録する。** URL・公開日・取得日を残す。
4. **著作権・個人情報。** 他者の文章を長く転載しない(引用は短く、出典明記)。個人が特定できる情報は書かない。
5. **お金・投資の記事。** 「必ず儲かる」等の断定をしない。リスクと「個人の経験であり助言ではない」旨を入れる。
6. **公開・投稿・送信はしない。** 成果物をファイルに保存するだけ。公開判断は人間が行う。
7. **文体(仮置き。変更可)。** です・ます調、読者に語りかける、親しみやすく具体的。
   「いかがでしたか」「まとめると」の連発、空虚な総括、過度な箇条書きなど、AIっぽい文章を避ける。
8. 事実と数字は、リサーチ成果物にあるものだけを使う。無いものを足さない。
