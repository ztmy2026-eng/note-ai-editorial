# 表紙の背景に使う写真(2026-11-09)
`assets/photos/<forest|night|sea|sky>/` に写真を置くと、表紙(`style: forest / night / sea / sky`)の背景に自動で使われる。無いときは、CGの背景になる。

- 出どころ: Unsplash(images.unsplash.com)。ライセンスは「Unsplash License」(商用利用・加工が可能。出典表示は不要。写真そのものを、そのまま売る・競合サービスにするのは不可)。
- **注意**: 作者名と写真ページのURLは、取得時に確認できていない(自動取得の都合)。ライセンスの公式ページは、取得時に開けなかった。気になるときは、Unsplashで写真を検索して、作者を確認する。
- 写真の中に、人・顔・文字・ロゴが写っていないものだけを使う(確認済み)。
- 持ち主が自分の写真を足したいときも、同じ場所に置けばよい(横長、幅1920px以上がおすすめ)。
