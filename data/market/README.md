# 市場データ(他の人の記事の、タイトルとスキ数)
金融・保険・投資・節約の分野で伸びている記事を分析するための入力です。**あなた自身の目で見た記事を、手で書き写して**ください。
プログラムでnoteのページを自動で読むことはしません(規約を確認できていないため)。

- `items.csv` に1記事=1行。列: `title`(タイトル), `likes`(スキ数), `topic`(空欄でOK。自動で分類), `source`(どこで見たか), `observed`(見た日)
- 記事の本文・作者名・個人情報は書かない(タイトルとスキ数だけ)。
- 数字は「見た時点」のもの。投稿からの日数やフォロワー数で大きく変わるので、**単純な比較はできません**。
- `python -m note_editorial analyze-market` で `analytics/market_insights.md` を作る。
