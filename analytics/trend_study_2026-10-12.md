# 節約ジャンルで「伸びている」投稿の分析(テーマ・タイトル・タイトル画像)

調べた日: 2026-10-12 / 依頼: 「noteでもYouTubeでもインスタでも、節約で伸びている投稿を分析して。アイデア段階で伸びるかは70%決まるらしいから」

## 先に、見えたことと、見えなかったこと(正直な範囲)
| 場所 | 見えたもの | 見えなかったもの |
|---|---|---|
| note | タグ(節約・節約術・固定費・家計管理・食費)の「人気順」の上位から、**36本のタイトル**と、上位8本の**見出し画像(実物)** | **スキ数・PVの数字は、ページに出ていなかった**。「人気順」は、スキだけでなく新しさなども混ざる並びなので、「伸びている」の証拠にはならない(目安) |
| YouTube | 節約チャンネルの人気ランキング(3チャンネルだけ) | 動画ごとの再生数・サムネイル(検索結果のページを読み込めなかった) |
| Instagram | 一般的な「伸びる型」の解説記事(マーケティング会社・個人ブログ) | 節約アカウントの実際の投稿・保存数 |

- つまり、**note=実物を見た(ただし数字なし)/ YouTube・Instagram=一般論だけ(二次情報)**。「傾向」とは言い切れず、**仮説**として扱う(36本は、30本の目安は超えたが、人気の証拠がない)。
- 「アイデア段階で70%決まる」は、出どころを確認できていない(検索でも、元の調査は見つからなかった)。数字は信じず、「企画の段階が大事」という考え方だけ使う。
- 集めたタイトル: `analytics/popular_titles_note_2026-10-12.csv`。

## 1. テーマ(何の話が上に来ているか)
上位36本を、話題で分けると(重なりあり):
- **「節約しているのに、疲れる・貯まらない・お金がない」型**(節約への疲れ、続かない、削れない): 「節約しているのに疲れる人へ」「『節約しなきゃ』を毎日考えるのに疲れた人へ」「節約してるのに、お金がない。」「食費はこれ以上削れない」「家計簿が続かない人は」。**節約の「やり方」より、「節約が続かない気持ち」に答える話**が多い。
- **「小さい出費は気にするのに、大きい出費は…」という、心理・思い込みの話**: 「ナス1個の値段は気にするのに、なぜ10万円の出費は許してしまうのか?」「『安いから買う』をやめたら、お金が残るようになった」。
- **固定費・値上げの時期の話**: 「値上げ時代に毎月の固定費を見直す5つのコツ」「固定費を見て怖くなった」「忍び寄る円安」(いまの季節に合う。**こちらがすでにやっている方向**)。
- **「自炊は本当に節約になる?」のような、常識を疑う話**: 食費・家計管理の3つのタグで、同じ記事が上位に出ていた(複数のタグで上位=強い関心の目安)。
- **意外な組み合わせ**: 「最新iPhoneの通信費は月210円相当。でもAIには月6,000円払っている」(いまの話題×自分のお金)。
- **実体験・公開系**: 「同棲1年目のガス代は年間いくら?」「毎月の詳細公開」(あなたの記事では、体験の空欄が必要になる型)。

→ **仮説**: 「節約のやり方リスト」より、**読者の気持ち(疲れた・怖い・なぜ?)に先に答える話**が上に来やすい。

## 2. タイトルの型(36本を数えた)
| 見た点 | 本数 |
|---|---|
| 数字を含む(「3つ」「5つのコツ」「30の習慣」) | 22/36(61%) |
| 読者に呼びかける(「〜な人へ」「子育て家庭」「初心者」) | 10/36(27%) |
| 悩み・感情の言葉(疲れた・怖い・続かない・貯まらない) | 9/36(25%) |
| 意外性・逆説(なぜ・のに・やめたら・本当に) | 9/36(25%) |
| 疑問・問いかけ(「?」「いくら」) | 8/36(22%) |
| 「」で鍵の言葉を強調 | 8/36(22%) |
| 【】の飾り | 6/36(16%) |
| 実体験・公開の言葉 | 6/36(16%) |
| 長さ | 10〜44字、中央値34字。25字以内は9本だけ |

- **気づき①: 上位のタイトルは、長い(中央値34字)。** 私たちの方針(15〜25字の短いタイトル)と、**食い違っている**。ただし、長い=人気の理由とは限らない(人気順は、長い説明つきの記事も上に出す)。**自分たちのデータ**(11本)では、短い「コンビニの…」が、インプレッション1,503で最大だった。どちらが正しいかは、**次の数本で、同じ週に長短を試して、インプレッション(見られた数)で比べる**のがよい。
- **気づき②: 数字(「3つ」「4つ」)は、61%の記事に入っている。** 私たちは、すでに使っている(これは合っている)。
- **気づき③: 「〜な人へ。」の呼びかけ+「〜な3つの考え方」の2段タイトル**が、上位に2本(「疲れる人へ」の2本)。メインの短い問い+サブの具体的な中身、という形。
- **気づき④: タイトル案の作り方(型)**:
  - 悩み型: 「節約しているのに疲れる人へ。〜3つの考え方」
  - 逆説・なぜ型: 「ナス1個の値段は気にするのに、なぜ10万円の出費は許してしまうのか?」
  - 常識を疑う型: 「自炊は本当に節約になる?食費だけで決めない3つの確認」
  - ビフォーアフター型: 「『安いから買う』をやめたら、お金が残るようになった。」(**体験の形**。あなたが書いていない体験は使えない。一般論の形に直す)

## 4. YouTube・Instagram(二次情報だけ。実物は見えていない)
- **YouTube**(解説記事より): タイトルは25字以内、「結論がわかる」「数字で具体的」「悩みがはっきり」を意識する。【】でメリハリをつける。サムネイルは、人物の顔+大きな文字+強調色。節約の人気チャンネルは「倹者の流儀」「大河内薫 / お金の教育」「よめ子」(ランキングだけ)。
- **Instagram**(解説記事より): カルーセルは、**1枚目(表紙)の出来で、ほぼ決まる**とされる。1枚目の型は、問い型・データ型・意外性型・問題提示型。1枚=1メッセージ(40〜80字)。表紙→本文→最後の行動の呼びかけ。
- 共通: **「悩みが一目でわかる」「数字」「人の顔か、強い色の大きな文字」**。noteの見出し画像の観察とも同じ向き。ただし、**元の調査の質は確認できていない**(マーケティング会社の発信)。

## 5. 「アイデア段階」で使える採点表(案。まだ週次企画には入れていない)
伸びやすさは、書く前の企画で決まる、という考えを使って、**企画の案ごとに、次の8点を○×で付ける**(○が多い案を、先に書く):
1. **悩み・感情**から入っているか(疲れた・怖い・続かない・なぜ?)
2. **ひとつの読者**を思い浮かべられるか(「節約しているのに貯まらない人」など)
3. **季節・ニュースに合っているか**(値上げの秋、暖房を使い始める時期)
4. **常識を疑う・意外な一言**があるか(「自炊は本当に節約になる?」)
5. **数字が1つ**入る(3つ・4つ)
6. **今日できる1つの行動**で終わるか
7. **一次情報の出典**(公的機関)が取れるか(取れない話は書かない)
8. **見出し画像が1枚で伝わる**か(絵や短い言葉で、話がわかる)

## 6. 次の企画案(上の型を使った、タイトルの案。本文の体験は作らない)
※ すべて「一般的な情報+出典」で書ける形。体験が必要な型は、あなたの言葉が入ったときだけ使う。
1. 節約しているのに疲れる人へ。やめていい節約3つ(悩み型)
2. 「安い」のに、なぜ増える?買い物の落とし穴3つ(逆説型)
3. 小さい出費は気にするのに、なぜ大きい出費は見逃すのか(逆説・「ナス1個」型。**そのままは真似しない**。心理の話は、出典を探す)
4. 自炊は本当に節約になる?食費だけで決めない3つの確認(**そのまま使わない**。同じ型で、別の話題に: 「まとめ買いは本当にお得?」)
5. 冬の電気代、先に見る3つ(季節型。すでに書いた電気の記事の続き)
6. 家計簿が続かない人は、最初から全部つけない(続かない型。出典: 公的機関の家計管理の案内などを探す)
7. 固定費の見直し、最初の1つはどれ?(固定費の続き。毎月の明細で見る)

## 7. 提案(まだ、何も変えていない)
1. **採点表(5.)を、週次企画(`weekly-plan`)に入れる**。企画の案ごとに○×を付けて、記録する。
2. **タイトルの長さの実験**: 次の2週間で、短い(15〜25字)案と、2段(メイン+サブ、30〜40字)の案を、半々で出して、**インプレッションで比べる**。結果を `analytics/` に記録する。
3. **見出し画像**: 「タイトルの文字を大きく」「強調は黄・赤」は、すぐ取り入れられる。人物・キャラクターは、保留中の件と合わせて決める(AI画像生成は使わない決まりのため、HTML/CSSで描ける簡単なキャラクターか、あなたが用意する絵)。
4. この調べ方は、**スキ数が見えないのが弱点**。あなたの記事は、これからもインプレッション・PV・スキを記録して、**自分たちのデータで確かめる**のがいちばん確か。

どれを入れるか、決めてください(「1と3を入れて」など)。
