# リサーチ: 電気・ガスの検針票の見方と、2026年11月ごろの料金補助の有無
実行ID: 2026-11-02_001 / 作成日: 2026-11-01

## 事実(出典つき)
- 2026年度の再エネ賦課金の単価は1kWhあたり4.18円。2025年度は3.98円で、0.2円上がった。経産省が2026年3月19日に公表した、と検索結果の要約にある。全国一律で、電力会社によらず同じ単価。(経産省の原文は未確認。関西電力の資料に基づく要約) [S1]
- 再エネ賦課金の適用期間は「2026年5月検針分から2027年4月検針分まで」とする情報がある。ただし別の解説記事は「2026年5月〜2027年3月」と書いており、食い違う。期間は記事に書かない。 [S1]
- 関西電力の資料では、月260kWhの従量電灯Aのモデルで再エネ賦課金は月1,086円、前年度より52円増(関西電力の例。他社・他の使用量では変わる)。 [S1]
- 夏の補助(7〜9月使用分)のあと、10月使用分は値引きなし(0円)と整理する民間解説がある。請求(検針)月と使用月は1か月ずれる、とも説明されている。 [S2]
- 2026年10月29日、高市首相が「12月から来年2月までの電気・ガス料金を補助する」と表明した、と報じられている。標準的な家庭で3か月約7千円の負担軽減との説明。(報道の要約。経産省・資源エネルギー庁の正式発表は未確認) [S3]

## 追加調査:推測・意見(AIの推測・試算の考え方)
- (推測)記事の見せ方として、公的に確認できた数字は「全国平均の電気は年間約3,950kWh・約13.2万円(令和4年度)」「待機電力は電気の約5%と環境省のページにある」「エアコンの室温を1℃緩和すると消費電力が冷房で約13%、暖房で約10%減る見込み」の3つ。この3つは、検針票の「使用量(kWh)」を見るときの目安にできる。
- (推測)令和4年度の全国平均を12か月で割ると、電気は月に約329kWh、約11,000円。ただし、これは年間平均で、季節・世帯人数・地域・オール電化かどうかで大きく変わる(S4の地方別でも、近畿の1.30t〜北陸の2.62tと差が大きい)。「あなたの家の目安」ではなく「全国平均の一例」と書く。
- (推測)支払金額÷使用量で単純計算すると、13.2万円÷3,950kWh=約33.4円/kWh。基本料金や再エネ賦課金などを含む「平均の支払単価」で、料金の「1kWhあたりの単価」とは違う。記事では「目安単価」と混ぜない。
- (推測)「いくら下がるか」は、「減らせるkWh × 単価」の掛け算で示せる。単価は、公式で確認できるまで、「仮に31円/kWhとおく」と前提を明記して使う。ただし、31円は、(1)の通り公式未照合。実際の請求は、燃料費調整額・再エネ賦課金・基本料金・プランの段階料金などで変わるため、「保証ではない」と添える。
- (推測)基本料金の違い(契約アンペア)は、公式の料金表を取れていないため、金額の試算はできない。「契約アンペアが高すぎると基本料金が上がる場合がある」と断定せず、「検針票の『契約』欄で、自分の契約を知るところまで」にとどめるのが安全。
- (推測)環境省の古いページ(2022年6月更新)の金額は、22.86円/kWhで計算されている。そのまま「約700円」と書くと、今の単価とずれる。kWh(30.2kWhなど)だけを使い、金額は今の単価で試算し直すのが安全。
- (推測)待機電力の「約5%」は古い情報の可能性があり、家庭によって差がある。「年間の待機電力を全部なくせる」わけでもないため、試算は「上限の目安」として書き、削減できる金額としては書かない。
- 「必ず下がる」「◯円得する」とは書かない。個人の体験・実績は、この章では創作していない。

## 追加調査:試算の例(公式の数字だけで作れるもの。すべて「目安・保証ではない」)
前提(共通): 単価は「仮に31円/kWh」とおく(公式未照合。[S10] 参照)。税込として扱う。燃料費調整額・再エネ賦課金・基本料金の違いは入れない。
- 試算A(使用量を減らす基本形): 月10kWh減らせた場合 = 31円×10kWh = 約310円(月)。年に直すと、120kWh×31円 = 約3,720円。「10kWhは、全国平均の月約329kWh[S4をもとにした推測]の約3%」という位置づけ。
- 試算B(エアコン): 冷房の設定を27℃→28℃にした場合の年間30.2kWh[S7]を、31円で計算 = 30.2×31 = 約936円(年)。S7の「約700円」は22.86円/kWhでの計算なので、金額は、今の単価で計算し直した値。環境省の前提(外気温・使用時間など)は、S7のページにある条件のもと。
- 試算C(照明): 白熱電球(54W)を1日1時間減らす場合の年間19.71kWh[S8]を、31円で計算 = 19.71×31 = 約611円(年)。蛍光ランプ(4.38W)は4.38kWh×31円 = 約136円(年)。LEDの数字は取れていないため、書かない。
- 試算D(待機電力の「上限の目安」): 年3,911kWh[S5]×約5%[S9]=約196kWh。31円で計算すると、約6,060円(年)。これは待機電力の合計の目安で、「全部なくせる」という意味ではない。
- 試算E(再エネ賦課金。単価の確認が取れたあとに使う): 4.18円/kWh[S1、経産省の原文は未照合]なら、月10kWh減ると、賦課金だけで約42円。使用量に比例するだけで、基本料金は変わらない。

## 追加調査:記事に使えそうな使い方
- 「検針票の使用量(kWh)の欄を見る → 全国平均の例(年約3,950kWh、月約329kWh[推測])と並べて、自分の家がどの位置か見る」という導入に使える。ただし、「平均より多い=無駄」とは書かない。
- 「使用量を減らす → 目安の単価 × 減らしたkWh」の計算式と、試算A〜Dを、表やfigにする。各試算に「目安・保証ではない」「前提:31円/kWh(仮)」と添える。
- 「契約アンペア・基本料金」は、公式の料金表が取れていないため、金額を出さずに「検針票のどの欄を見るか」だけを書く。持ち主が、自分の電力会社の公式料金表を確認して、体験として書く場合は、持ち主の言葉だけを使う。
- 公開前に持ち主が公式で確認すると良いもの: (a)全国家庭電気製品公正取引協議会「よくある質問」の目安単価、(b)経産省のニュースリリース(2026-03-19)の賦課金単価、(c)自分の電力会社の料金表・燃料費調整のページ、(d)資源エネルギー庁・環境省(デコ活)の最新の省エネの金額。
- 補助(12月〜2月使用分)は、報道ベースのままにとどめ、数字(約7千円など)は、公式で確認できるまで試算に混ぜない。
