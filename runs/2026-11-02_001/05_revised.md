# 電気代、たった5つ変えるだけで、年約14,400円お得に!

【画像:cover.png】

こんにちは、人生最適化中の会社員です。今日は、電気代がいくらお得になるかを、環境省の数字で計算してみます。

結論から言うと、次の5つを変えると、年約14,400円(月にならすと約1,200円)の目安です。

【画像:fig1.png】

1. 家電の待機電力を減らす:年約9,400円
2. 冷蔵庫の設定を「強」から「中」にする:年約2,000円
3. 暖房を1日1時間減らす:年約1,300円
4. 冷房の設定を27℃から28℃にする:年約1,000円
5. 白熱電球を1日1時間減らす:年約650円

毎月届く電気代、合計の金額だけ見て、そっと閉じる。そんな人もいると思います。でも、使っている家電のどこを変えれば、いくら動くのか。それが分かると、「やってみようかな」が変わります。

金額はすべて目安です。全部がそのまま当てはまる人は多くありません。当てはまる分だけ、拾ってください。

## 先に「ものさし」を決めます

「電気を1減らしたら、何円お得か」を出すには、電気1あたりの値段が要ります。電気の量は kWh(キロワットアワーと読む、使った電気の量の単位)で表します。

環境省の調査(令和4年度=2022年度、速報値)では、全国の1世帯あたりの電気は年間3,950kWh、支払金額は13.2万円でした。割り算はこちらでしました。

13.2万円 ÷ 3,950kWh = 約33円/kWh

これは全国平均から出した目安の単価です。基本料金のような固定の部分も混ざっているので、実際に減る額とはずれることがあります。以下、この「1kWh=約33円」で計算します。

環境省の節電のページには、それぞれの工夫で減る電気の量(kWh)が載っています。そのkWhに33円をかけました。

## 1. 家電の待機電力を減らす:年約9,400円

使っていないのに、コンセントにつないでいるだけで流れる電気を、待機電力といいます。

環境省のページには、家電製品の待機時の消費電力をすべて減らせた場合、年間で285kWhの節電、とあります。

285kWh × 33円 = 9,405円で、約9,400円です。5つの中で、いちばん大きい数字です。

やり方の例は、使わない家電のプラグを抜く、スイッチ付きの電源タップでまとめて切る、です。ビデオデッキなど、抜くと設定が消えるものは、「表示OFF機能」などを使う、と環境省は案内しています。

ただし、これは「すべて減らせた場合」の数字です。冷蔵庫のように、抜けないものもあります。実際に減る額は、ここから小さくなると考えてください。

## 2. 冷蔵庫の設定を「強」から「中」にする:年約2,000円

環境省のページによると、冷蔵庫の設定温度を「強」から「中」にした場合、年間で61.7kWhの節電です。

61.7kWh × 33円 = 約2,036円で、約2,000円です。

ボタンを1回切り替えるだけで、お金のかからない工夫です。ただし、食品が傷まないように注意してください。

## 3. 暖房を1日1時間減らす:年約1,300円

環境省のページには、暖房(設定温度20℃)の使用時間を1日1時間減らすと、年間で40.73kWhの節電、とあります。

40.73kWh × 33円 = 約1,344円で、約1,300円です。冬が近いので、今シーズンからすぐ試せます。

## 4. 冷房の設定を27℃から28℃にする:年約1,000円

環境省のページには、冷房の設定を27℃から28℃にした場合、年間で30.2kWhの節電、とあります。

30.2kWh × 33円 = 996.6円で、約1,000円です。冷房は夏の話なので、来年の夏の目安です。

## 5. 白熱電球を1日1時間減らす:年約650円

環境省のページには、白熱電球(54W)の点灯を1日1時間減らすと、年間で19.71kWhの節電、とあります。

19.71kWh × 33円 = 約650円です。LEDなどに替えている家では、これより小さくなります。

## 5つを合わせると

| 変えること | 年間の節電(kWh) | 年の目安 |
|---|---|---|
| 待機電力を減らす | 285 | 約9,400円 |
| 冷蔵庫「強」→「中」 | 61.7 | 約2,000円 |
| 暖房を1日1時間減らす | 40.73 | 約1,300円 |
| 冷房27℃→28℃ | 30.2 | 約1,000円 |
| 白熱電球を1日1時間減らす | 19.71 | 約650円 |
| 合計 | 約437 | 約14,400円 |

437.34kWh × 33円 = 14,432円で、約14,400円です。月にならすと約1,200円です。

【画像:fig2.png】

ほかにも、環境省のページには、冷蔵庫に食品を詰め込まず半分にすると年間43.8kWh(33円で約1,400円)、液晶テレビ(20インチ)の視聴を1日1時間減らすと年間15.00kWh(約500円)といった数字が載っています。この2つは、上の合計には入れていません。

## 数字を読むときの注意

- 金額は、全国平均の単価(約33円/kWh)で計算した目安です。保証ではありません
- 環境省のこのページは、2022年6月に更新された過去のページです。今の機器や暮らしに、そのまま当てはまるとは限りません
- 待機電力は「すべて減らせた場合」、暖房・冷房・電球は、環境省が置いた使い方の条件での数字です。住まいや家電で変わります
- 5つ全部を変えた人の数字です。1つだけでも、その分の金額はお得になります

## まとめ

- 5つ変えると、年約14,400円(月約1,200円)の目安
- いちばん大きいのは待機電力で、年約9,400円(すべて減らせた場合)
- すぐできるのは、冷蔵庫の設定(年約2,000円)と、暖房の時間(年約1,300円)

まずは、冷蔵庫の設定を見てみるところから、始めてみてください。
