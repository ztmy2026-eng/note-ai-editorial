- 事実: `data/past_articles/` には6本ある。PV・収益・フォロワー増は6本とも「データなし」(null)。スキ数はメール通知から拾った推定値で、取り消しで減ることもある。値は 5(味玉100円の記事)、4(仕組み作りの記事)、3(お金の健康診断)、1(光回線の記事)、1(ポイントの記事)、1(保険の確認5つ、2026-10-04)。
- 事実: `analytics/facts.md` では、スキ率もテーマ別の平均もすべて「データなし」。比べられる数字はない。
- 事実: 通信費に近い過去記事は「光回線選び」の1本(スキ1)だけで、スマホ代そのものを扱った記事はない。直近の 2026-10-04 の記事は「その場で決めずに確認する順番」という構成(スキ1)。
- 仮説(推測): PVがないため、どの型の反応がよいかは判断できない。スキ数の差(1〜5)は小さく、公開日や通知の取りこぼしで説明できてしまう範囲なので、傾向とは扱わない。
- 仮説(推測): `analytics/hypotheses.md` の H1〜H4 は架空のサンプルデータ(n=5)をもとにしており、どれも「検証中」。そのため参考程度にとどめる。今回の候補1は「確認する順番+チェック表」という持ち帰れる基準の型で、H1(失敗+基準)にも近い。ただし体験の部分は筆者の回答待ち。
- 仮説(推測): `analytics/market_insights.md` は8件しかなく(目安は30件以上)、傾向とは扱わない。疑問形タイトルは1件しかないので、実験枠で試す材料にとどめる。

### 候補1: 確認する順番を一緒に見る(週次企画)
- **タイトル案**: 3案
  - 本案: スマホ代、見直す前に見る3つ
  - 予備案1: スマホ代を下げる前の確認3つ
  - 予備案2: 毎月のスマホ代、まず何を見る?
- **想定読者**: 25〜40歳の会社員。毎月のスマホ代が高い気はしているが、乗り換えるかどうかを決めきれていない人。
- **読者の悩み**: 安いプランの広告はよく見るけれど、自分が何を確認すればいいのか分からない。乗り換えて逆に高くついたら困る。
- **切り口**: 乗り換えは勧めない。総務省のポータルサイトが案内している順番(データ使用量をつかむ → 合うプランを選ぶ → 不要なオプションを外す)[S1] に沿って、マイページで「今のプランとデータ量」「オプション」「乗り換えにかかるお金(違約金・端末代の残り・手数料)」[S2] の3つを、「調べてみたら」という姿勢で読者と一緒に確認する。割引の条件は数字の出典がないので、「条件と期間を書面とマイページで確認する」という一般論として短く扱う。
- **構成**: 見出し7個
  1. 冒頭のフック+結論(乗り換え先を探す前に、マイページで3つを並べて見る)【画像:fig1 見直しの順番】
  2. 失敗1:今のプランと使ったデータ量を知らない(マイページで確認できる [S1])
  3. 失敗2:使っていないオプションが付いたまま(料金・解約条件・必要性を確認する。気づいたらすぐ申し出る [S3][S4])
  4. 失敗3:割引の条件を勘違いしている(条件と期間を書面で確認する。契約書をその場で確認するという助言 [S3])
  5. 失敗4:乗り換えのとき、端末代や解約の費用を見ていない(違約金・分割代金の残り・事務手数料やSIM代 [S2])【画像:fig2 確認チェックリスト】
  6. 僕自身の失敗(`【要入力:僕自身の失敗(スマホ代・契約内容の確認について)】`。書くとよい失敗の例を2〜3個添える)
  7. まとめ(箇条書き)+困ったときの相談先(消費生活センター等 [S4][S5])+次回予告+免責・出典
- **CTA**: fig2 のチェックリストを手元に置いて、今月のマイページを1回開いてもらう。次回の記事(翌日の節約テーマ)の予告とフォロー。アフィリエイトは入れない(00_plan.md の指定どおり)。
- **過去記事との関係**: 似ている部分がある。「光回線選び」(通信費)とはテーマが近く、2026-10-04 の保険の記事とは「決める前に確認する順番」という型が近い。ただし、乗り換えで取り戻した話ではなく「契約内容を見る順番」なので切り口は違い、スマホ代としては新規。

### 候補2: オプションだけ先に見る
- **タイトル案**: 3案
  - スマホのオプション、何が付いてる?
  - 外し忘れたスマホのオプションを探す
  - スマホ代、まずオプションだけ見る
- **想定読者**: 契約したときに勧められたオプションを、そのままにしている会社員。
- **読者の悩み**: 何が付いているのか覚えておらず、確かめ方も分からない。
- **切り口**: 3つの確認のうち、オプションだけに絞って深く見る。マイページで確認し [S1]、料金・解約条件・必要性を見て、不要なら申し出る [S3][S4]。
- **構成**: 見出し5個
  1. 冒頭+結論(マイページの「オプション」欄を1回見る)
  2. 失敗:何が付いているか覚えていない
  3. 失敗:解約の条件を見ずに放置している
  4. 僕自身の失敗(【要入力】)
  5. まとめ+相談先+出典
- **CTA**: マイページのオプション欄を開いてもらう。
- **過去記事との関係**: 新規。過去記事にオプションを扱ったものはない。

### 候補3: 乗り換え前にかかるお金を並べる
- **タイトル案**: 3案
  - 乗り換える前に、かかるお金を並べる
  - スマホの乗り換え、先に見る費用3つ
  - 乗り換えの前に、端末代の残りを見る
- **想定読者**: 乗り換えを考え始めている会社員。
- **読者の悩み**: 月額の安さだけを見ていて、乗り換えのときにかかるお金を把握していない。
- **切り口**: 違約金(定期契約・最低利用期間)、端末の分割代金の残り、乗り換え先での事務手数料やSIM代 [S2] を、金額は書かずに「どこで確認するか」として並べる。
- **構成**: 見出し5個
  1. 冒頭+結論
  2. 失敗:契約期間と違約金を見ていない
  3. 失敗:端末の分割代金が残っている
  4. 失敗:乗り換え先の手数料を見ていない+僕自身の失敗(【要入力】)
  5. まとめ+相談先+出典
- **CTA**: 契約書面とマイページで、契約期間と端末代の残りを確認してもらう。
- **過去記事との関係**: 「光回線選び」と近い(乗り換えの費用)。ただし今回は、取り戻した話ではなく、乗り換えの前に確認する話。

### 候補4:【実験枠】疑問形タイトル×データ量だけを見る
- **タイトル案**: 3案
  - 毎月のデータ量、知っていますか?
  - スマホのデータ、何GB使ってる?
  - 自分のデータ量、すぐ答えられますか?
- **想定読者**: プランをなんとなく選んだまま、使った量を見たことがない会社員。
- **読者の悩み**: 自分のプランが多すぎるのか少なすぎるのか分からない。
- **切り口**: 総務省の案内順の最初の一歩「データ使用量を把握する」[S1] だけを扱う。マイページで直近のデータ量とプランを並べ、見合っているか、かけ放題が必要かを考える [S1]。実験の内容は「疑問形のタイトル」と「1つの行動だけに絞る記事」。疑問形は自分の記事ではまだ試していない(過去記事のうち疑問形は1本で、数値データはない)。市場データでは疑問形は1件しかなく、傾向とは扱えない。比べる指標はスキ数とPV(取れる場合)で、候補1(数字入りタイトル)と比べる。
- **構成**: 見出し5個
  1. 冒頭(質問を投げかける)+結論
  2. マイページでデータ量を見る場所
  3. プランと並べて見る(見合っているか、かけ放題は必要か)
  4. 僕自身の失敗(【要入力】)
  5. まとめ+次の一歩(オプションの確認へ)+出典
- **CTA**: 直近のデータ量をメモしてもらう。
- **過去記事との関係**: 新規。疑問形・単一行動型は未検証の切り口で、hypotheses.md の「新切り口案C(疑問形タイトル)」を試すもの。

### 候補5: 契約するその場で見ること
- **タイトル案**: 3案
  - スマホの契約、その場で見る3つ
  - お店でスマホを契約する前に見ること
  - 分からない契約は、その場で決めない
- **想定読者**: 機種変更や新しい契約で、近いうちにお店へ行く予定の会社員。
- **読者の悩み**: お店で説明が早く進んでしまい、何に同意したのか分からないまま帰ってしまう。
- **切り口**: 総務省・消費者庁の助言 [S3](契約書をその場で確認する、月々の支払額を確かめる、オプションは料金・解約条件・必要性を確認して不要なら断る、分からなければ契約しない)を、お店で使える確認メモにする。
- **構成**: 見出し6個
  1. 冒頭+結論
  2. 失敗:月々の支払額を確かめずにサインする
  3. 失敗:勧められたオプションをそのまま付ける
  4. 失敗:よく分からないまま契約する
  5. 僕自身の失敗(【要入力】)
  6. まとめ+相談先 [S4][S5]+出典
- **CTA**: お店に行く前に、確認メモをスマホに保存してもらう。
- **過去記事との関係**: 似ている。2026-10-04 の保険の記事(その場で決めない)と同じ型。違いはテーマが通信費であること。

## おすすめ
候補1 — 週次企画の本案なのでこれにする。読者価値:乗り換えを勧めずに「何を、どの順番で見るか」が手元に残り、fig2 のチェックリストがそのまま使える。実現性:骨格(使用量→プラン→オプション)と乗り換え費用の3点は、出典 [S1][S2][S3][S4] で書ける。リサーチで未照合とされた数字を含む事項(初期契約解除制度の8日間、2022年7月の消費者保護ルール)は使わない。各社の料金・割引の数字・違約金の金額も書かない。体験の入れやすさ:筆者が自分のマイページを開くだけで「僕自身の失敗」が書けるので、体験を作らずに埋めやすい。

## あなたに聞きたいこと
- 今使っているスマホの契約で、マイページを開いて「今のプラン」「直近数か月のデータ使用量」を見たことはありますか。見た(または今回見た)なら、プランと使っている量は見合っていましたか(金額やGB数を書いてよければ、その数字も)。
- 契約したときに付けたオプションで、今は使っていないもの、付いていることを忘れていたものはありましたか。気づいたあとに外しましたか。
- 割引の条件や期間を勘違いしていたこと(終わっていたのに気づかなかった、など)はありますか。
- 乗り換えを考えたことはありますか。そのとき、端末代の残りや契約期間・違約金を確認しましたか(確認しなかった、途中でやめた、なども含めて)。
- 「僕自身の失敗」の節で、どの失敗を書くのが一番書きやすいですか(プラン・データ量/オプション/割引/乗り換えの費用のどれか)。
