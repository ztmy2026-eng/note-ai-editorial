# 批評: お菓子と飲み物に、平均で年18万円。外食とほぼ同じ

(検算の結果: 菓子類9,211+飲料5,859=15,070円/月、×12=180,840円。外食16,563×12=198,756円。15,070÷16,563=0.9099で約91%。15,070÷30=502.3円。どれも 01_research.md [S1] と合っています。食料の内訳12項目を全部足すと94,895円で、食料の月平均とぴったり同じでした。つまり内訳に抜けはありません。年・対象(2025年平均・二人以上の世帯・月平均=年計÷12)も研究どおりです。「菓子類は穀類・肉類・魚介類より多い」「飲料は乳卵類・酒類・果物より多い」も、数字のとおりです。数字の誤りはありません。問題は、数字の「読ませ方」と「穴」です。)

## 問題点
1. 【重大】問題1 「なぜ、こんなに積もるのか」の節と、「自分の家と比べる方法」の手順2 — 研究には「表の費目別の金額(94,895円)は、他の世帯への贈答品やサービスの支出を含む」とあります[S1]。内訳12項目の合計が94,895円とぴったり同じなので、菓子類9,211円にも、手土産やお歳暮用のお菓子が入っている可能性が高いです(どれだけ入っているかは、分かりません)。ところが本文は、15,070円をすべて「コンビニのついで買い」「レジ前」「自販機」の積み重ねとして説明しています。これは穴です。さらに、世帯主の平均年齢は60.7歳です。読者(25〜40歳)が「うちはそんなに買っていない」と感じて離れる理由になります。比べる手順にも「手土産を入れるか」の決まりが無く、平均とずれた範囲で比べてしまいます。 → (a)本文53行目の注記を、エンゲル係数の説明から「この金額には、よその家に贈るお菓子なども入っています」の1文に書き換え、「なぜ積もるのか」の前に置きます。(b)あるあるの場面は「たとえば〜という場面もあります」の形にして、「これが全部の理由」とは読めないようにします。(c)比べる手順2に「手土産・贈り物で買ったお菓子も足す(平均の数字に入っているため)」を加えます。

2. 【重大】問題2 「見直すなら、小さい仮の例を1つ」の節と結び(88行目) — お金の効果が「1,000円×12=年12,000円」しかありません。これは方針で禁じている「減らせば減る」の計算そのものです。本文も「当たり前の計算なので」と自分で認めています。さらに結びは「買い物のときの感覚が少し変わるかもしれません」です。読者は「で、私はいくら得するの」の答えをもらえずに終わります。方針(2026-11-07「着眼点は得」、2026-11-11「当たり前の話にしない」)の両方に届いていません。ただし正直に言うと、このデータだけでは、大きな「得」の額は作れません。 → 1,000円の例は消します。かわりに、研究にある数字で「比べる」驚きを足し、得の弱さを補います。
   - 二人以上の世帯の電気代は月13,219円、通信(スマホ代など)は月11,672円です[S1]。お菓子と飲み物の15,070円は、どちらよりも多くなります。「電気代やスマホ代の節約記事はよく読まれるのに、それより大きい項目がある」と書けます。電気代やスマホ代の記事は、過去にインプが多かったテーマなので、読者の関心ともつながります。
   - 年180,840円は、外食16,563円の約11か月分です(180,840÷16,563=10.9)。「お菓子と飲み物の1年分で、外食ほぼ11か月分」と言えます。
   - 得の額は、記事で決めつけず、読者が自分で出せる式にします。「(自分の月額−15,070円)×12=平均との年の差」。仮の例として「月2万円の家なら、(20,000−15,070)×12=年59,160円、平均より多い」を、仮の例と書いて1つだけ置きます。これは「減らせば減る」ではなく「平均と比べて」(方針の(2))の得になります。

3. 【重大】問題3 「自分の家と比べる方法」と単身の段落(78行目) — 物差しが「二人以上の世帯(平均2.87人)の月15,070円」の1本しかありません。一人暮らしや二人暮らしの読者は、比べる相手がいません。本文は「そのまま当てはまらないかもしれません」「注意して見てください」で止まっていて、方針が禁じている「問いかけ・注意で終わる」形になっています。 → 計算の仮の目安を1本足します。「15,070÷2.87=1人あたり約5,251円/月(年約63,010円)。人数で割っただけの大まかな目安で、子どもと大人の違いなどは考えていない」。二人暮らしの目安(×2=約10,500円)も、同じ注記をつけて書けます。そのうえで、手順3を「世帯の人数×5,251円と並べる」に変えます。単身世帯の内訳が未確認であることは、1文に短くします。

4. 【中】問題4 「菓子類と飲料」の定義(22行目)と、比べる手順2 — 「細かい線引きは、調査の定義によります」と書いていますが、これでは何も説明していません。読者が迷うのは、ペットボトルの水、コンビニのいれたてコーヒー、アイス、喫茶店のコーヒーなどです。比べる相手の「外食」に何が入るかも、研究では確認できていません。題は「外食と比べて」なので、ここがあいまいだと驚きが弱くなります。 → 公開前に、統計局の「収支項目分類」(stat.go.jp。つながるドメイン)で、菓子類・飲料・外食の主な中身を研究係に追加で確かめてもらいます。確認できた例だけを本文に2〜3個書きます。確認できなければ、本文は「迷うものは、毎月同じ決まりで数える」の1文だけにして、定義の箇条は消します。確認していない例は書きません。

5. 【中】問題5 「菓子類と飲料を合わせた15,070円は、調理食品や野菜・海藻より大きい。外食の次に来る規模」(51行目)と、fig1 — 2つの項目を足したものと、1つの項目を比べています。これは比べ方として公平ではなく、気づいた読者は「足せば大きくなるのは当たり前」と思います。fig1も、3位の野菜・海藻(9,715円)を飛ばして、穀類と肉類を並べています。都合のいい数字だけ選んだように見えます。 → 2つ対2つで比べます。「肉類8,520円+魚介類6,293円=14,813円。お菓子と飲み物の15,070円は、肉と魚を合わせた額より多い」。こう書けば公平で、驚きも強くなります。fig1は「外食/菓子類+飲料/肉類+魚介類/調理食品」にするか、野菜・海藻も入れます。

6. 【中】問題6 冒頭(7〜13行目) — 2段落目と3段落目に、6個の数字と2つの式が詰まっています。驚きの「外食とほぼ同じ」が出るのは3段落目の最後です。そのあとすぐ4段落目で「あなたの家がこの金額だと言いたいわけではありません」と、言い訳から入ります。スマホで読む人は、数字の山と言い訳で、ここで離れます。 → 1文目で驚きを見せます。例:「お菓子と飲み物に、平均で月15,070円。電気代(13,219円)より多く、外食(16,563円)の約9割です」。年の額や式は、その次の段落か fig2 に回します。平均であることの注意は、「二人以上の世帯の平均です」の短い1文で冒頭に入れ、詳しい説明はあとの節にまとめます。

7. 【中】問題7 「この数字は何の平均か」の節と、エンゲル係数の段落(53行目) — 全体の約4分の1が、用語の整理・注記・つまずき・値上げの注意・免責です。とくにエンゲル係数の段落は、記事の主張に使っていない説明です。方針の「いまの目的は人を集めること。仕組みの解説で終わらない」に反します。まとめ(104〜108行目)も、冒頭をそのまま繰り返しています。 → エンゲル係数は消します(残すのは、問題1の「贈答品も入る」の1文だけ)。定義の節は「出典・対象(2.87人・60.7歳)」の2行にします。まとめは3行にします(電気代より多い/肉と魚より多い/自分の額との差を出す式)。削った分は、問題2・3・5の内容に回します。

8. 【中】問題8 「なぜ、こんなに積もるのか」の節 — 根拠が全部推測で、「(これは推測です)」「(これも推測です)」が続きます。読者には「何も分かっていない節」に見えます。57行目は「〜と思う人もいると思います」で、「思う」が重なっています。66行目の「どれも、そんな人もいると思います」は、日本語として成り立っていません。 → 節を半分にします。冒頭に一度だけ「ここは調査の数字ではなく、推測です」と書き、あるあるは2〜3個にします。「どれも、そんな人も〜」は消し、「1回が数百円なので、使った気がしにくいのかもしれません」の1文にまとめます。

9. 【軽微】問題9 「穀類(ごはん・パン・麺など)」(47行目) — 穀類の中身は、研究では確かめていません。たぶん正しいのですが、出典のない補足です。 → 問題4の分類の確認で一緒に確かめます。確認できなければ「穀類(主食の類)」程度にするか、かっこ書きを消します。

## 有料記事としての可能性
成立しません。理由: 中身は、公的な平均を並べたものと、自分で比べる式だけです。誰でも統計局のPDFから同じことができます。持ち主の実際の数字(自分の家のお菓子・飲み物代)や、続いた工夫の記録もありません。足りない要素は次のとおりです。(1)持ち主の家の実際の月額と、平均との差(持ち主が出した数字だけ)。(2)人数別の目安と、分類に迷う品目の判定表(画像のチェックリスト)。(3)数か月記録したときの変化。いまは無料の集客記事として、問題2・3・5を直して「驚き+自分で比べられる」に寄せるのが正解です。
