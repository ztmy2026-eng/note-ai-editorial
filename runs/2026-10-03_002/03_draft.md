# 新社会人の給与明細、見るべき項目はここ。1年目と2年目で変わる控除のチェック表

初めての給与明細を開いて、こう思ったことはありませんか。「額面はこれくらいのはずなのに、振り込まれた額が少ない」。

ここで一度、説明用の架空の例を置きます。新社会人のAさんは、入社して最初の給料日に明細を開きました。上のほうに大きな数字があり、下のほうに見慣れない項目が並び、いちばん下に実際の振込額があります。Aさんは「どこで減ったのか」を説明できず、そのまま閉じてしまいました。

この記事は、Aさんのような人が明細を上から順に読み、「額面と手取りの差」を自分の言葉で説明できるようになるための案内です。金額や料率は載せません。制度の細かい数字は人や時期で変わるので、覚えるより「どこを見て、どこで確かめるか」を持っておくほうが長く使えるからです。

## 明細は3つのブロックで読む

会社によって見た目は違いますが、多くの明細は大きく3つに分かれています(一般的な傾向で、勤務先の様式は必ず自分の明細で確認してください)。

- 支給:基本給や手当など、会社から支払われるお金
- 控除:支給から差し引かれるお金
- 差引支給額:控除を引いたあとの、実際に振り込まれる額

「額面と手取りの差」は、ほぼ控除の欄で説明がつきます。迷ったら、まず控除の欄だけを見てください。

## 控除は「税金」と「社会保険」に分けて眺める

控除の欄に並ぶ項目は、大きく2つのグループに分けると整理しやすくなります。

- 税金のグループ:所得税、住民税など
- 社会保険のグループ:健康保険、厚生年金、雇用保険など

項目名は会社の明細によって表記が異なります。ここでは「この欄はどちらのグループだろう」と仕分けできれば十分です。仕分けできない項目だけ印を付けておき、後で聞く先を決めます。

## 「1年目と2年目で変わる」とは何か

新社会人向けの税金の解説を扱う専門家向けメディア「マネーイズム」には、1年目の所得税・社会保険料と、2年目の住民税をシミュレーションした記事があります[S5]。タイトルから分かるのは、1年目と2年目では給与から引かれるものの構成が変わる、という切り口が成り立つことです。

ただし、編集部ではこの記事の本文までは確認できていません。そのため、何がいつから、どのくらい変わるのかは、この記事では述べません。ここは必ず、次のどれかで確かめてください。

- 勤務先の人事・総務・給与担当への問い合わせ
- 国税庁や自治体、日本年金機構など、公的機関の案内ページ
- 自分の明細の控除欄が、月ごとにどう動いているか

「2年目に手取りの感覚が変わるかもしれない」と知っておくだけでも、心づもりが変わります。実際にどう変わるかは個人の状況で異なります。

## 確認チェック表

コピーして、手元のメモに貼って使えます。

**毎月の給料日に**
- [ ] 支給・控除・差引支給額の3ブロックを見分けられた
- [ ] 振込額と、明細の差引支給額が一致している
- [ ] 前月と比べて、控除の欄に増えた項目・消えた項目がないか見た

**初めて明細を受け取ったとき**
- [ ] 控除の項目を、税金と社会保険に仕分けした
- [ ] 意味が分からない項目に印を付けた
- [ ] 印を付けた項目を、給与担当に聞く質問として書き出した

**年に一度、見直すとき**
- [ ] 1年間の明細を並べて、控除の構成が変わった月がないか見た
- [ ] 変わった月があれば、その理由を給与担当か公的機関の案内で確かめた

**2年目に入る前に**
- [ ] 「2年目に控除の構成が変わる」と言われる点を、勤務先か公的機関で確認した
- [ ] 手取りが変わる可能性を前提に、毎月の支出を見直す日を決めた

## 分からないときの聞き方と、一次情報の探し方

印を付けた項目は、そのまま質問にできます。たとえば次のような聞き方です。

> 「給与明細の○○の欄は、何のための控除ですか。来年以降、変わることはありますか」

項目名をそのまま書いて聞けば、相手も答えやすくなります。社内で聞きにくいときは、公的機関のページで項目名を調べる方法もあります。

給与に関する統計の一次情報を探すときは、厚生労働省の「賃金構造基本統計調査(初任給)」の調査概要ページが入口になります[S1]。ニュースで初任給の数字を見て不安になったときも、まず元の調査を確認すると、見出しだけで焦らずに済みます。なお、この記事では初任給の数字そのものは扱いません。

## 注意:この記事でできないこと

この記事は、明細の読み方と確認先を整理した一般的な案内であり、税金や社会保険についての助言ではありません。制度の内容や金額、開始時期は、勤務先や個人の状況によって異なります。具体的な判断が必要なときは、勤務先の担当者や公的機関、必要に応じて税理士などの専門家に確認してください。
