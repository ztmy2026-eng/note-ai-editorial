# 企画候補: 給与明細の「引かれるお金」(手取りが思ったより少ないと感じたとき)

※ 週次企画(runs/2026-11-03_001/00_plan.md)があるため、候補1は週次企画そのまま(タイトル本案・予備案・失敗パターン・図もそのまま使う)。候補2〜5は同じテーマの別の切り口(形式検査のための予備)。
※ リサーチ(01_research.md)で一次情報を確認できなかった数字は、企画に入れていない。具体的には、協会けんぽ・健保組合の健康保険料率、介護保険料・子ども・子育て支援金の率、保険料の会社と本人の折半、賞与の保険料のしくみと上限、源泉徴収税額表の月々の額、新卒の住民税の扱い。健康保険は「自分の料率は、加入先のサイトか会社の担当者で確かめる」と案内するだけにする。
※ 使える数字はリサーチで確認できたものだけ: 厚生年金保険料率18.3%[S4]、雇用保険の労働者負担0.5%(令和8年度・一般の事業)[S5]、所得税は5%〜45%の7段階[S3](課税所得にかかる率で、月給にそのまま掛けるものではないと注意を書く)、源泉徴収の納付は翌月10日まで[S1]、住民税は前年の所得がもと[S6]で、特別徴収は6月〜翌年5月の12回[S7、信頼度中]。住民税の均等割の金額[S6]は、ページが文字化けしていたため、原文を確認し直すまで使わない。

## 過去記事の傾向(仮説)
- 事実(data/past_articles・analytics/hypotheses.md): ほぼ同じテーマの記事「手取りと額面の差、どこへ行く?」(10-20企画、10-21公開、theme: newcomer)は、インプ61・PV3・スキ6(2026-10-25時点。公開から日が浅い時点の数字)。
- 事実: テーマ別では newcomer は n=1(上の1本)だけで、インプ61・PV3。saving-insurance は n=9 で平均インプ1,061・平均PV26。
- 事実: タイトルの型別では、短い型 n=13 が平均インプ847、2段型 n=8 が平均インプ292。インプが少なかった題には、制度・専門用語の題(NISAの枠36、年末調整337、手取りと額面61)が含まれる(weekly_policy.md 2026-10-27の節)。
- 事実: 診断型(お金の健康診断)はPV率8.2%で、全体の2.8%より高い(持ち主のシート分析、2026-10-14)。疑問形タイトルの平均スキ率は119.6%(n=3)、疑問形でないものは42.0%(n=18)。
- 事実: 10-22・10-23の2本は、記録時点で数字が入っていない。この2本の反応については何も言えない。
- 仮説(推測): 前回の「手取りと額面」は、題に「額面」という言葉が入っていた。今回は「手取りが思ったより少ない」という読者のつぶやきを主役にし、短い型・ピクトグラム表紙(briefcase または receipt)にそろえる。これは仮説台帳の「実験すること1」(低いテーマを、伸びた記事と同じ短い型・表紙で書き直して比べる。H1・H2・H4)の1本としても使える。
- 仮説(推測): 前回と中身が重なりすぎると、読者にとって新しさが無い。今回は「どこへ行くか」の説明より、「手取りが少ないと感じた日に、明細のどこを、どの順で見るか」(確認の順番)に重心を置き、専門用語は後ろに回す。
- 市場データ(他の人の記事)は8件のみで、30件未満のため傾向としては扱わない。

### 候補1: 手取りが少ないと感じた日に、明細を見る順番(週次企画の本案)
- **タイトル案**:
  1. 「手取りが思ったより少ない」の中身を見る(本案)
  2. 給与明細の、引かれる項目3つ(予備案1)
  3. 手取りが少ないと感じたら、見る場所(予備案2)
- **想定読者**: 25〜40歳の会社員。振込額は毎月見るが、明細の「控除」の欄はあまり開かない人。転職した年や、ボーナスの月に「あれ、少ない」と感じた人。
- **読者の悩み**: 手取りが思ったより少ない。でも、何がどれだけ引かれているのか、どこから見ればいいのか分からない。控除の名前を聞いてもピンとこない。
- **切り口**: 「引かれるお金」を、社会保険料・所得税・住民税の3つのグループに分けて眺めるだけで入口になる、という整理。制度の名前や率は後ろに回し、先に「明細の見る順番」(fig1)を示す。数字は確認できたものだけ(厚生年金18.3%、雇用保険の本人負担0.5%など)。健康保険は率を書かず、「加入先か会社で確かめる」にする。
- **構成**:
  1. あいさつ+フック(あるある:「給料日に振込額だけ見て、明細は開かない。そんな人もいると思います」)
  2. 結論を先に: 引かれるお金は3つのグループ。「支給」→「控除」の順に、名前を一つずつ確かめる(fig1: 確認の順番)
  3. 失敗パターン1: 手取りだけ見る(所得税は毎月仮に引かれ、年末調整で精算される流れ。「戻る」「得する」とは書かない)
  4. 失敗パターン2: 控除の名前を知らない(厚生年金・雇用保険・健康保険・所得税・住民税を、何のためのお金かだけ一言ずつ。住民税は前年の所得がもと)
  5. 失敗パターン3: ボーナスの手取りを額面で考える(賞与の明細にも控除の欄がある。自分の明細で確かめる。数字は書かない)
  6. つまずきやすいところ(読者のあるある。税率5〜45%を月給にそのまま掛けてしまう、など。「〜という人もいるかもしれません」の形)
  7. まとめ(fig2: チェックリスト)+お礼+次回予告
- **CTA**: 「次の給料日に、明細の『控除』の欄を開いて、項目の名前を3つのグループに分けてみてください。分からない名前があれば、会社の担当者に聞くのがいちばん早いです」。アフィリエイトは入れない(00_plan.md のとおり)。
- **過去記事との関係**: 似ている(10-20企画「手取りと額面の差、どこへ行く?」とほぼ同じテーマ)。違いは、題を読者のつぶやき型・短い型にしたことと、中身を「どこへ行くか」から「見る順番」に寄せたこと。同じテーマを型と表紙を変えて書くので、仮説台帳の実験1(テーマか、型・表紙か)を切り分ける材料にする。前回と同じ文の使い回しはしない。

### 候補2: 社会人2年目の6月に、手取りが変わって見える理由
- **タイトル案**:
  1. 6月の給料、「なんか少ない」と思ったら
  2. 住民税は、去年の分を今年払う
  3. 手取りが6月に変わるのは、住民税かも
- **想定読者**: 新卒2年目前後の会社員と、その後輩・家族。転職して住民税の払い方が変わった人。
- **読者の悩み**: 昇給したはずなのに、6月から手取りが減って見える。理由が分からない。
- **切り口**: 住民税だけを主役にする。前年の所得がもと[S6]、特別徴収は6月〜翌年5月の12回[S7、信頼度中]。新卒の扱いは一次情報で未確認なので、「という人もいる」程度にとどめる。均等割の金額は原文の確認が取れるまで書かない。
- **構成**:
  1. あいさつ+フック
  2. 結論: 住民税は前の年の所得で決まる
  3. 天引きは6月から翌年5月の12回
  4. 特別徴収と普通徴収の違い
  5. つまずきやすいところ(読者のあるある)
  6. まとめ+お礼+次回予告
- **CTA**: 6月の明細と5月の明細を並べて、住民税の行だけ比べる。
- **過去記事との関係**: 似ている(10-20企画の記事が「2年目に手取りが減って見える」に触れている)。住民税だけに絞る点が新しい。ただし今は11月で、6月の話は時期が合わない(来年5月ごろの企画向き)。

### 候補3:【実験枠】 あなたの明細は、どこで「少ない」と感じる?(当てはめ型チェック)
- **タイトル案**:
  1. 手取りが少ない理由、どのタイプ?
  2. 「思ったより少ない」の正体、3タイプで見る
  3. 給与明細、どこで引っかかってる?
- **想定読者**: 手取りが少ない理由を、自分で切り分けたい会社員。
- **読者の悩み**: 明細の項目が多くて、どれのせいか分からない。全部読む気になれない。
- **切り口**: 診断・当てはめ型(仮説H5「診断・問いかけ型はPV率・スキに効くかもしれない」、状態=検証中を試す)。「社会保険料が気になるタイプ」「所得税が気になるタイプ」「住民税が気になるタイプ」に分け、読者が自分の明細を見て当てはめる表を作る。金額や率の比較はしない。
- **構成**:
  1. あいさつ+フック
  2. 結論: 引かれるお金は3つのグループで見られる
  3. タイプ1: 社会保険料(健康保険・厚生年金・雇用保険)
  4. タイプ2: 所得税(毎月の仮の金額と年末調整)
  5. タイプ3: 住民税(前年の所得がもと)
  6. つまずきやすいところ(読者のあるある)
  7. まとめ(当てはめ表)+お礼+次回予告
- **CTA**: 自分の明細を見て、いちばん気になったグループに印をつける。
- **過去記事との関係**: 新規の切り口(手取り×診断型は初)。診断型は「お金の健康診断」(PV率8.2%、n=1)と同じ型だが、テーマが違う。公開7日後のPV÷インプとスキ÷インプを、同じ週の他の記事と比べる。

### 候補4: 年の途中で入社・転職した人の、年末の明細
- **タイトル案**:
  1. 転職した年、前の会社の書類ある?
  2. 年の途中で入社したら、年末に見る1枚
  3. 前の会社の「源泉徴収票」、捨ててない?
- **想定読者**: 今年、転職・中途入社した会社員。
- **読者の悩み**: 年末の手続きで、前の会社の書類を求められたが、どこにあるか分からない。
- **切り口**: 年の途中で入社した人も年末調整の対象になりうる。前の会社の源泉徴収票が確認できないと年末調整ができず、確定申告で精算することになる[S8]。時期(11月)に合う。
- **構成**:
  1. あいさつ+フック
  2. 結論: 前の会社の源泉徴収票を先に探す
  3. 見つからないとき、どうなるか(確定申告で精算[S8])
  4. 今の会社の担当者に聞くこと
  5. まとめ+お礼+次回予告
- **CTA**: 前の会社の源泉徴収票が手元にあるか、今日確かめる。
- **過去記事との関係**: 似ている(10-23企画の年末書類の記事が、同じ国税庁 No.2674 を出典にしている)。題に「源泉徴収票」が入ると、制度名が主役になりやすい(インプが低めの型、推測)。

### 候補5:【実験枠】 手取りの「引かれる」を、会社の側から見る
- **タイトル案**:
  1. 給料から引いた税金、会社はいつ納める?
  2. 引かれたお金は、翌月どこへ行く?
  3. 明細の「控除」、会社のその後の仕事
- **想定読者**: 「引かれる」がなんとなく損に感じている会社員。
- **読者の悩み**: 天引きは一方的に取られている感じがする。どこへ、いつ行くのか知らない。
- **切り口**: 未検証の新しい切り口(会社が納める流れを主役にした記事は過去に無い)。所得税は会社が翌月10日までに国へ納める[S1]、住民税の特別徴収は会社が翌月10日までに市区町村へ納める[S7、信頼度中]。保険料の流れは、今回の出典で確認できた範囲だけにする(折半は書かない)。
- **構成**:
  1. あいさつ+フック
  2. 結論: 引かれたお金は、会社が代わりに納めている
  3. 所得税の流れ
  4. 住民税の流れ
  5. 社会保険料(確認できた範囲だけ)
  6. まとめ+お礼+次回予告
- **CTA**: 明細の控除の行を、「国へ」「市区町村へ」「保険へ」に分けてみる。
- **過去記事との関係**: 新規。ただし10-20企画の記事が「どこへ行くか」を扱っていて、重なる部分がある。保険料の流れの出典が足りず、実現性は中くらい。

## おすすめ
候補1 — 週次企画の本案。読者価値: 「手取りが思ったより少ない」と感じたその場で、明細の「支給」→「控除」→3つのグループ、という見る順番がすぐ使える。専門用語を後ろに回すので、明細を開かない読者にも入りやすい。実現性: 健康保険の料率や賞与のしくみなど未確認の数字を使わなくても、確認できた数字(厚生年金18.3%、雇用保険の本人負担0.5%、住民税は前年の所得がもと)と、fig1(確認の順番)・fig2(チェックリスト)で記事が成り立つ。前回の手取り記事とテーマが近いので、型・表紙を変えた比較(仮説台帳の実験1)の材料にもなる。筆者の体験の入れやすさ: 方針(2026-10-25)により体験欄は標準では置かず「つまずきやすいところ(読者のあるある)」で書ける。新卒1年目の筆者には身近な話題なので、持ち主が自分の明細を見た感想を送ってくれれば「## 僕自身の失敗」に入れやすい。
