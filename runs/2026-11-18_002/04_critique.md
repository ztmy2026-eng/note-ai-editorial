# 批評: 「家賃は捨て金」を、35年分のお金で比べる

検算メモ(批評側): 本文の数字(月返済101,623/119,255/138,546円、税34,000円、修繕23,450円、35年後の差の9個、並ぶ家賃の9個とその丸め)は、すべて calc_result.txt と一致した。calc_rent_own.py の差の式(売値−頭金−持ち家の35年の支払い+家賃×420)と、並ぶ家賃の式も正しい。フラット35の4,215万円・3,602万円、修繕積立金の335円、住宅ローン控除の0.7%・13年は 01_research.md の確認済み出典[S1][S6][S7]と一致。要約のみの数字([S2][S3][S4][S9][S10][S11]、金利の現状)は使われていない。問題は、数字の「説明のしかた」と「入れていないものの書き方」にある。

## 問題点
1. 【重大】35行目「国土交通省のガイドライン(令和6年6月改定)にある全体平均の目安、1平方メートルあたり月335円」 — 335円は全体の平均ではない。01_research.md[S6]では「地上20階未満・延床5,000平方メートル未満・機械式駐車場を除く」の平均で、ほかの区分は252円・271円・255円・338円。出典の説明が間違っている(執筆メモ154行目は正しく書けているのに、本文だけ違う。calc_rent_own.py の冒頭の説明文も「全体平均」と誤っている) → 本文を「国土交通省のガイドライン(令和6年6月改定)で、地上20階未満・延床面積5,000平方メートル未満のマンションの平均(機械式駐車場を除く)とされる、1平方メートルあたり月335円」に直す。スクリプトの説明文も同じく直す。
2. 【重大】34行目・41行目「一般的な税率として、固定資産税1.4%と都市計画税0.3%」 — [S5]では、1.4%は「標準税率」、0.3%は「制限税率(上限)」で、市町村が条例で決める。0.3%を「一般的」と書くと、上限を標準のように見せることになり、持ち家の負担を高めに見せる方向に偏る。さらに、税率の出典[S5]が本文末の「情報源」に入っていない → 34行目を「固定資産税等:家の評価額を価格の60%と仮定し、固定資産税は標準の税率1.4%、都市計画税は上限の0.3%をかけた額(どちらも仮に置いたもの。都市計画税は市町村で違い、上限より低いところもあります)。月に直すと34,000円」に直す。[S5]は要約からの取得なので、原文(https://www.soumu.go.jp/main_content/000759190.pdf)で1.4%と0.3%を確認できたら、情報源に足す。確認できなければ「標準」「上限」の言葉は消して、「仮に置いた税率」とだけ書く(「一般的な」は、どちらの場合も使わない)。
3. 【重大】45〜57行目「入れていないもの」 — 持ち家の負担を「減らす」向きの抜けが書かれていない。(a)[S5]にある住宅用地の特例(土地の課税標準が200平方メートル以下の部分は価格の6分の1)を入れず、価格全体の60%に35年間ずっと同じ税率をかけている。(b)評価額は35年間変わらない前提になっている。どちらも、入れると持ち家の負担が減る。逆に、持ち家の負担を増やす抜けで、出典があるもの((c)専有部分のリフォーム費用は修繕積立金に原則含まれない、(d)機械式駐車場があれば別に加算[S6])も書かれていない。今のままだと「持ち家に不利な抜け」が読者から見えず、57行目の「両方が抜けています」が、確かめられない主張になる → 一覧に次の4行を足す。「土地の税金を軽くする特例(住宅用地の特例):入れていません。入れると、持ち家の負担が減ります[S5]」「家の評価額の変化:35年間同じとしました。実際は見直されるので、税額は変わります(推測)」「部屋の中のリフォーム費用:入れていません。修繕積立金は共用部分の工事のためのお金で、部屋の中のリフォームは原則含まれません。入れると、持ち家の負担が増えます[S6]」「機械式駐車場の費用:入れていません[S6]」。あわせて、57行目を「持ち家の負担を増やすもの・減らすもの、賃貸の負担を増やすものが、どれも抜けています」にする。
4. 【重大】141行目【リンク任意:住宅ローン比較系】 — 削除する。理由は3つ。(1)書き出し(export.py)はこの印を消さないので、noteの本文にそのまま出てしまう(図の指示・執筆メモは消されるが、これは消されない)。(2)この実行には 00_plan.md が無く、週次方針の「自然につながる記事だけ末尾に書く」の対象ではない。(3)記事の主張は「どちらが得かは決めない・特定の選択をすすめない」(22行目・24行目)なのに、最後に住宅ローン比較への導線を置くと、「買う」側へ読者を押す形になる。editorial_rules.md の「特定の金融商品の推奨や勧誘をしない」にも近づく → 141行目の1行を消す。付けたいなら、02_ideas.md にある診断アプリへの案内(どちらにも寄らない)にする。
5. 【中】タイトル「「家賃は捨て金」を、35年分のお金で比べる」 — 方針の形式(20字・前提を入れない・疑問形でない・専門用語なし)は満たす。ただし、「比べる」で止まっていて、読む前に「何が分かるのか・意外な点は何か」が見えない(2026-11-09「何が得かがひと目で分かる」、2026-11-11「抽象的な題を避ける」「当たり前にしない」に弱い)。「35年分」は期間の枠なので仮定の条件には当たらず、残してよい → 結論の意外さを題に出す。案:「「家賃は捨て金」は、家賃の額で外れる」(18字)/「「家賃は捨て金」、35年で比べると入れ替わる」(21字)/「「家賃は捨て金」が当てはまる人、外れる人」(20字)。並ぶ家賃の「13.9万円」は仮の試算の数字なので、題には入れない(仮定の条件を題に入れない方針と、実際の目安だと誤解される危険のため)。
6. 【中】15行目の見出し「先に結論:35年後に残るお金は、入れ替わります」、111行目「持ち家のほうが残ります」、135行目「金利2%・売値50%なら、約13.9万円」 — 103行目には「(この仮の試算の中での話です)」があるが、流し読みする人が目にする見出し・具体例・まとめには「仮の試算」の断りが無い。とくに、まとめの13.9万円が、一般的な分かれ目の数字として独り歩きする危険がある → 15行目を「先に結論:仮の試算では、家賃と売値で入れ替わりました」に、111行目を「…あたりから、この試算では持ち家のほうが残ります」に、135行目を「…金利2%・売値50%の仮の試算では、約13.9万円(管理費などは入れていない)」に直す。見出し101行目の「入れ替わる境目が分かる」も、「分かる」は言いすぎなので「入れ替わる境目の目安が見える」にする。
7. 【中】59〜69行目「毎月の負担は、金利でここまで変わる」 — 「意外と大きい」が記事の主役のはずなのに(02_ideas.md の切り口)、いちばん効く数字が本文に無い。(a)持ち家の月の合計(返済+税+修繕)が書かれていない。返済10万円台でも、合計は月16万〜20万円近くになるはずで、67行目の「上乗せ分」はこの合計を見せて初めて伝わる。(b)「家賃は捨て金」への一番の答えになる「持ち家でも戻ってこないお金」(35年分の利息・税・修繕積立金の合計)が無い。批評側の検算では、利息だけで金利1%で約670万円、3%で約2,220万円になる → calc_rent_own.py に「月の合計」と「35年の利息・税・修繕積立金の合計」の出力を足して、calc_result.txt を作り直し、その出力の数字だけを使って、63〜65行目の箇条書きに合計を並べ、「持ち家でも、家賃のように出ていって戻らないお金がある」という段落を1つ足す(批評側の手計算の値は、記事に使わない)。66〜67行目の「金利が上がるほど、月々の返済は増えていきます」は当たり前なので消す。
8. 【中】22行目「自分の前提を入れると、どのあたりで入れ替わるのか」を見る記事、と約束しているのに、読者が自分の数字で並ぶ家賃を出す方法が書かれていない。137行目「同じ形で比べてみると」は、やり方が無いので行動につながらない → スクリプトの式は「並ぶ家賃=持ち家の月の合計−(35年後の売値−頭金)÷420か月」と同じなので、この形で1つ見せる(例:金利2%・売値50%なら、月の合計−(2,000万円−400万円)÷420。数字は問題7で足すスクリプトの出力を使う)。「物件価格・借りる額・金利が違う人は、銀行などの返済シミュレーションで月の返済額を出してから、ここに入れる」の一言を添える。
9. 【中】39行目「建売住宅4,215万円や中古マンション3,602万円と、同じくらいの規模感」 — 試算はマンション想定なのに、戸建ての「建売住宅」を例に出し、同じ調査の「マンション(新築)5,882万円」[S1]を出していない。都合のよい近い数字だけを選んだように見える → 「同じ調査で、新築マンションは5,882万円、中古マンションは3,602万円。今回の4,000万円は、その間の、中古寄りの数字として置きました」に直す。新築マンションの値段で計算すると結果が変わる(持ち家の負担が増える)ことも一言書く(推測と明記)。
10. 【中】52行目 住宅ローン控除 — 「条件を満たす住宅では…0.7%が13年間」だけだと、多くの家に当てはまるように読める。[S7]では、13年は認定住宅・ZEH水準・省エネ基準適合住宅の場合で、年間の控除限度額があり、「その他の住宅」(令和6年以降入居)は原則0。参照したのも「新築等」のページで、中古は未確認 → 「国税庁によると、新築などで省エネの基準を満たす住宅では、年末のローン残高の0.7%が、年ごとの上限つきで13年間差し引かれます。基準を満たさない住宅は原則対象外です。中古住宅の扱いや、借りる額の上限は今回確認できていないので、数字に含めていません」に直す。
11. 【中】115行目「持ち家のほうが残る側に入るには、より高い家賃を払っている必要があります」 — 誰が家賃を払うのかが分からず、持ち家の人が家賃を払うようにも読める → 「つまり、売値が低いほど、金利が高いほど、比べる相手の家賃がかなり高くないと、持ち家のほうが残る結果にはなりません(この試算の中の話です)」に直す。
12. 【中】7行目のフック「買えば、最後は自分のものになる」と、試算のモデルがずれている。この言葉が指すのは「35年後もそのまま住める」ことだが、試算は「35年後に売って現金にする」形で、その価値を売値で代わりに見ている。ここを書かないと、「住み続ける人の話が入っていない」と感じた読者が離れる → 123行目の箇条書きに「35年後も住み続ける場合:その家の価値は、この試算では『売値』で代わりに見ています。賃貸の人は35年後も家賃を払い続ける点は、この試算の外です」を足す。
13. 【軽微】冒頭の場面(9〜11行目) — 「飲み会や親戚の集まりで、…耳にした人もいると思います」は、読者の場面として「〜人もいると思います」の形で書けていて、筆者(僕)の体験にはなっていない。創作の体験には当たらないので残してよい。ただし、11行目「そんな場面は、きっとあります」は言い切りで、あるあるの書き方(「〜という人もいると思います」)から外れている。あるあるが9行目に2つ、11行目、67行目で計4か所あり、上限の2〜3か所を超えている。author_notes.md がこの実行に無く、「Claudeの提案(未確認)」の記録も無い → 11行目を「…調べ始めるのも少し怖い。そんな人もいるかもしれません」に直し、9行目後半の「反対に、〜」の文を消して3か所以内にする。修正版を作るときに author_notes.md を作り、残したあるあるを「Claudeの提案(未確認)」として記録する。

## AIっぽさ
- 「つまり、」が22行目と115行目、「〜わけです」(99行目)、「この不確かさが、結果を大きく左右します」(89行目)は、まとめ役の決まり文句。89行目は「35年後の売値は、今は分かりません。そして、そこがいちばん結果を動かします」のように短く言い切る形にし、22行目の「つまり、」は消す。
- 「言葉の応酬ではなく、数字で並べてみます」(13行目)は硬い。「言い合いではなく、数字で並べてみます」にする。
- 「数字にならない部分も、書いておきます」(121行目)は前置きだけの文。消して、見出しのすぐ後に箇条書きを置く。
- 「(推測)」「(推測を含みます)」が125〜127行目で3回続き、機械っぽい。節の冒頭に「この節は、数字で確かめていない、推測を含む話です」と1回書き、各行の(推測)は消す。
- 111行目と113行目の「1つ目。」「2つ目。」は、説明書のような形。「たとえば、金利2%で〜」「金利1%で〜なら」と、つないで書く。

## 有料記事としての可能性
成立しない(この編集部の方針で、有料記事は作らない)。仮に有料で考えても、材料が仮の試算1つで、読者が自分の数字を入れる方法(問題8)も、持ち家で戻らないお金の合計(問題7)も無いため、無料の比較記事との違いが出ない。足りないのは、読者が自分の家賃・価格・金利で並ぶ家賃を出せる式か計算表、新築・中古の価格帯ごとの試算、筆者自身の住まいの判断(持ち主が書いた場合のみ)の3つ。
