# 株クイズアプリ 設計書(2026-10-25)

## 目的
投資の勉強。PERなどの用語と、投資したい4分野の知識を、毎日5問のクイズで身につける。持ち主(プログラミング初心者)がスマホで毎日使う。

## 決まっていること(持ち主の指示)
- 置き場所:スマホで開く Claude のページ(アーティファクト)。ソースは `quiz/index.html` に置く。
- 毎日5問。レベルは 基礎・中級・上級。
- 分野:投資の基礎知識 + 半導体・AI / エネルギー・資源 / 医薬・ヘルスケア / ロボティクス(各、基礎・中級・上級)。
- 不正解リスト:間違えた問題は翌日以降に再出題。**答えの位置・選択肢を変える**(位置で覚えさせない)。
- **BeReal風の連続日数**:毎日の習慣づけを最優先にする(下記)。
- 追加アイデアは全部採用(下記)。
- **問題の数字は実在の数字**。必ず**いつ時点か(基準日)と出典**を問題に明記する。相場感をつかむのが目的。

## 画面
1. **ホーム**:大きな連続日数(🔥N日)、今日の状態(未/完了)、直近のカレンダー。
2. **クイズ**:4択または数値入力。答えた直後に、正解と解説(+ 実数字なら基準日・出典)。
3. **不正解リスト**:間違えた問題、卒業までの残り回数、次の出題日。
4. **成績**:レベル別・分野別の正答率、苦手ランキング、バッジ。
5. **用語帳**:出てきた用語の意味・式・例。

## BeReal風の連続日数
- 1日1回「今日の5問」を完了すると連続日数が+1。1日でも空くと0に戻る。
- ホームに「今日まだ」を目立たせる(赤い表示+経過時間)。完了したら完了時刻を記録し、カレンダーに点(完了時刻が遅いと「遅め」印)。
- 日付は**日本時間(Asia/Tokyo)**で数える(0時で切り替え)。
- ※スマホの通知は、ページからは送れない。通知が欲しい場合は、Claudeの定期タスクやカレンダー予定で別途(今回は作らない。必要なら次の段階)。
- 「もっとやる」で追加5問ができるが、連続日数は増えない。

## 出題ルール(毎日5問)
- 内訳:不正解リストから最大2問(期日が来たもの)+ 現在のレベルの新規 + 復習。
- 不正解リストの再出題:選択肢をシャッフルし、**言い換え問題(同じ知識の別の聞き方)**があればそちらに切り替える。ダミー選択肢も入れ替える。
- 卒業:再出題で**2回連続正解**でリストから外れる。間隔は 翌日 → 3日後 → 7日後。
- 日によって「投資の基礎」「分野」を交代。苦手分野は多めに。
- レベル自動調整:直近の正答率が8割超で、次のレベルを提案。

## 追加機能(全部採用)
連続日数・バッジ(7日/30日連続など)/「もっとやる」/用語帳/計算問題(数値入力)/実例の読み解き問題/レベル自動調整/苦手分野の重点出題。

## 問題データの方針(重要)
- 数字は**実在の数字**を使う。ただし、次のルールを必ず守る:
  - 問題ごとに `asof`(基準日、例 2026-09-30)と `source`(出典名とURL)を持たせ、画面に表示する。
  - **確認できた数字だけ**使う(WebSearch/WebFetch で出典を確認)。確認できなければ、数字は入れず、概念の問題にする。
  - 相場感がズレないよう「例:日経平均のPERは約15倍前後(2026-09時点、日本取引所グループ)」のように、基準日つきで書く。変動が大きいもの(株価など)は「時点」を強調し、画面に「数字は基準日時点。最新ではありません」と出す。
  - 古くなった数字の問題は、`asof` が90日より古いと画面で「古い数字」と表示する。更新はClaudeに頼む。
- 画面に「勉強用であり、投資の助言ではありません」と常時表示。特定銘柄の売買を勧める問題は作らない。
- 用語の定義は一般的なもののみ。迷う内容は入れず、間違いに気づいたら持ち主が教えられる(「この問題が変」ボタンで記録)。

## データ構造
- 問題:`id, level(basic|mid|adv), field(basics|semi_ai|energy|health|robotics), type(choice|number), question, choices, answer, explain, term, asof?, source?, variants[]`
- 進捗(ページに保存):`streak, lastDoneDate, doneLog[{date, time}], wrongList[{id, stage, nextDue, streakOK}], stats, badges`
- 保存先:アーティファクトの保存機能(共有ではなく本人のみ)。使えない場合はブラウザの保存。保存できないときは画面に出す。

## 作り方
- 1ファイル(HTML+JS)。問題は別ファイル `quiz/questions.js` に分ける(問題の追加・更新を、ページと分けて頼めるように)。
- 出題ロジック(5問の選び方・卒業判定・連続日数)は、小さな関数にして、テストを書く(日付またぎ・日本時間・卒業判定)。
- 初期版:各分野×各レベルに数問ずつ(まず約120問)。持ち主が触ってから、問題を増やす。

## 範囲外(今回やらない)
スマホ通知、他人との比較、リアルタイム株価、売買の助言、AIがその場で問題を作る機能。
