# スマホで操作するガイド(外出先でのちょっとした作業)

PCを使わずに、スマホの **Claudeアプリ** と **ダッシュボード** だけで、毎日の作業ができるようにするためのメモです。

毎朝の記事づくりは、クラウドが自動で進めます(日本時間 7:45)。あなたがやるのは、次の4つだけです。

1. 何が待っているかを見る
2. 空欄(【要入力】)に、自分の体験を書く
3. noteとSNSに貼り付けて投稿する(投稿は、必ずあなたの手で)
4. 投稿したと記録する

## 入口は2つ

| 入口 | 使うとき | 場所 |
|---|---|---|
| **ダッシュボード** | 見る・コピーする・数字を入れる | https://claude.ai/artifact/QKDCrkrJ6MNY3VHRu9uixv (ブラウザのホーム画面に追加しておくと開きやすい) |
| **Claudeアプリの Code タブ** | システムに「実行して」と頼む(承認・記録・更新) | アプリ下部の **Code** → **New Session** → リポジトリ `ztmy2026-eng/note-ai-editorial`、ブランチ `claude/ai-note-editorial-system-2u1vuq` を選ぶ |

- ダッシュボードは、自分のアカウントでログインした人だけが開けます。**未公開の記事が入っているので、他の人に共有しないでください。**
- Code タブの画面の細かい表示は、アプリのバージョンで変わることがあります。違うときは、「Code」「新しいセッション」に近い項目を探してください(私はスマホ画面を直接見られないため、公式ドキュメントの説明に基づいています)。
- 一度開いたセッションは、続けて使えます。毎回新しく作る必要はありません。

## 1日の流れ

**① 朝(通知かダッシュボードで確認)**
ダッシュボードの「やること」に、記事ごとのカードが出ます。上のバッジが「空欄あり」「確認待ち」「投稿待ち」のどれかを示します。
上の「〇〇時点の記録です」が古いときは、Code タブで **「ダッシュボードを更新して」** と送ってください。

**② 「空欄あり」のとき**
1. カードの空欄に、**実際にあったことだけ**を書く(書いた内容は端末に自動保存されます)。
2. 全部書くと「Claudeに送る文をコピー」が押せます。コピーして、Code タブに貼り付けて送る。
3. Claudeが空欄に反映して、編集・批評をやり直し、本文を見せます。
4. 内容を読んで、よければ **「承認2してよい」** と返信する。Claudeが公開準備を進めます。
   ※ 承認は、あなたがこの返信をしたときだけです。Claudeは勝手に進めません。

**③ 「確認待ち」のとき(空欄はないが、承認2がまだ)**
カードの「確認を頼む文をコピー」を貼り付けて送る → 本文を読む →「承認2してよい」。

**④ 「投稿待ち」のとき**
1. 「タイトルをコピー」「本文をコピー」→ noteアプリに貼り付けて投稿する。
2. 投稿したnoteのURLを、カードの欄に入れる(https:// で始まるもの。`?` 以降は自動で外れます)。
3. SNSの案が、URL入りでコピーできるようになります。URLを入れるまでは、URL入りの案はコピーできません(【記事URL】のまま投稿するミスを防ぐためです)。
4. 「投稿したと記録する文をコピー」を貼り付けて送る → 記録され、次の記事を作れる枠が空きます。

**⑤ 数字(インプ・PV・スキ)**
ダッシュボードの「数字」タブで、そのまま入力できます。保存できないときは、数字が元に戻り、赤い表示が出ます(入力は無駄にならないよう、もう一度入れてください)。

## 先にできないこと・注意

- **画像**(見出し・図・Instagram用)は、ダッシュボードの記事のカードに、本文に出てくる順番で並びます。**「画像をコピー」**を押して、noteの編集画面に貼り付けます。貼り付けできないときは、画像を長押しして保存します。画像が出ていないときは、「ダッシュボードを更新して」と送ってください。
- **7:45〜8:15(日本時間)は、操作を避けてください。** 毎朝の自動実行が同じ場所に保存するため、重なると衝突することがあります(自動で直す手順は入れてありますが、避けるのが確実です)。
- Code タブのセッションで、Claudeが **「ArtifactData が使えない」** と答えたときは、ダッシュボードの更新だけPCで行います(コピーや数字入力は、これまでどおり使えます)。初回に一度、「ダッシュボードを更新して」と送って、動くか確かめてください。
- 自動実行を今すぐ動かしたいときは、claude.ai/code の **Routines** から `note-daily-run` を手動で実行できます(使用量を消費します。1日1本の上限は効きます)。
- システムは、noteにもSNSにも**自動では投稿しません**。貼り付けと投稿は、いつもあなたの手です。

## PCが切れているとき(スマホだけで、全部できる手順)
PCの電源が入っていなくても、**クラウド側の私**が動きます(毎朝の自動実行も、同じクラウドです)。ダッシュボードが古くても、チャットだけで最後まで進められます。

**始め方**: Claudeアプリの **Code** → **New Session** → リポジトリ `ztmy2026-eng/note-ai-editorial`、ブランチ `claude/ai-note-editorial-system-2u1vuq`。
(Remote Control で、PCにつないだセッションは、PCが切れると使えません。クラウドの新しいセッションを使ってください。)

**言えば動く言葉**(リポジトリの `CLAUDE.md` に、私の動き方を書いてあります)
| 言う | 起きること |
|---|---|
| 今日の状況 | いま待っていることを、短く教えてくれる |
| (ダッシュボードの「Claudeに送る文」を貼る) | 体験の空欄に、あなたの言葉だけを入れる。本文を見せてくれる。承認はしない |
| 適当に付け加えて、3案出して | 3案を出す(付け足しは「提案・未確認」と記録)。選んだ案だけを使う |
| 承認2してよい | 公開準備をして、**タイトルと本文を、チャットにそのまま出す**(コピーしてnoteに貼れる) |
| 投稿用の文を出して | タイトル・本文・SNS案を、チャットに出す |
| 投稿した。URLは https://note.com/… | 「投稿した」と記録して、SNS案のURLを埋める |
| 数字を入れて。インプ○、PV○、スキ○ | 数字を記録する |
| 見送りにして | 投稿しない記録にする(ファイルは残る) |
| ダッシュボードを更新して | クラウドで動けば更新する。動かなければ「PCが入っているときに」と答える |

**変更は、必ず保存(push)されます。** 私が、作業の最後にコミットして、GitHubに送ります。
**画像**(見出し・図・Instagram)を新しく**作る**のは、クラウドでは動かないことがあります(PCで作り直します)。すでにできている画像は、ダッシュボードのカードでコピーできます。ダッシュボードに出ていないときは、GitHub上の `runs/<実行ID>/images/` にもあります(長押しで保存できます)。
